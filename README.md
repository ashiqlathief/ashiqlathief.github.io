# Ashiq Ali Abdul Lathief: portfolio

Gatsby static site. All content lives in `src/data.js`; components in `src/components/` render it; styles are in `src/styles/main.css`. Media is served as-is from `static/`.

```bash
npm install --legacy-peer-deps
npm start        # http://localhost:8000
npm run build
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on push to `main` (set Pages source to "GitHub Actions").
